# Fernando Lucatelli Nunes — website files

This folder is a complete static website. Upload its contents to the web root while preserving the `ABSTRACTS` and `SLIDES` directories.

The homepage is `index.html`. All local links and assets have been checked. The contact address is assembled only when the visitor clicks the email link and is displayed in an obfuscated form to reduce automated harvesting.

The site is institution-neutral outside `Academic_Positions.html`; that page contains the complete appointments and affiliations record. The enclosed `CV.pdf` is linked with the exact case-sensitive filename used throughout the site.
